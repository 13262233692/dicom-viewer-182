15//! System calls for getting the terminal size.
16//!
17//! Getting the terminal size is performed using an ioctl command that takes
18//! the file handle to the terminal -- which in this case, is stdout -- and
19//! populates a structure containing the values.
20//!
21//! The size is needed when the user wants the output formatted into columns:
22//! the default grid view, or the hybrid grid-details view.
23//!
24//! # Example
25//!
26//! To get the dimensions of your terminal window, simply use the following:
27//!
28//! ```no_run
29//! # use term_size;
30//! if let Some((w, h)) = term_size::dimensions() {
31//!     println!("Width: {}\nHeight: {}", w, h);
32//! } else {
33//!     println!("Unable to get term size :(")
34//! }
35//! ```
